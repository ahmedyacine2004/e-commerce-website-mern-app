# Ecommerce Frontend

A modern ecommerce web application built with React and Vite focused on performance, clean design, and smooth user experience.

## Tech Stack
React, Vite, JavaScript, Tailwind CSS, Material UI, Axios, React Router, Framer Motion

## Features
Product listing, product details, shopping cart, authentication support, responsive UI, animations

## Setup
```bash npm install && npm run dev ```

## Build
```bash npm run build ```
